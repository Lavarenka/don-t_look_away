VOICE-OVER / ОЗВУЧКА

Put recorded lines here: voice/<lang>/<KEY>.ogg  (also .wav or .mp3)
Положите записи сюда: voice/<язык>/<КЛЮЧ>.ogg

KEY = the key from lang/strings.csv. Examples / Примеры:
  voice/en/INTRO_03.ogg   Voicemail: "Mr. Kornev, hello..."
  voice/en/INTRO_04.ogg ... INTRO_07.ogg
  voice/en/LVL_01.ogg     Grandma's note (read aloud)
  voice/en/LVL_28.ogg     "Don't turn around."
  voice/en/NUR_24.ogg     "Now you're it, Misha."

Any subtitle shown via _say(), note or intro line plays its file automatically if it exists.
Если файла нет — игра просто показывает субтитры.
